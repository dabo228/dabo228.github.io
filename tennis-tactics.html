发球局
稳定模式 关键分
发向身体或反手附近 → 第一拍打深中路或继续压同侧 → 先获得中性相持 → 再用高低、长短变化展开布局

容错高，适合关键分

主动模式 进攻
外角旋转发球拉开对手 → 观察对方是否快速回中 → 回中早就打回头，留在外侧就打空档 → 第一拍后跟进底线内
追身发球套路 稳妥
追身发球 → 对手无法完整转体 → 回球角度小 → 第一拍打深中路 → 向底线内移动一步

深中路看似不进攻，但可以限制对手打出大角度，为自己争取进入相持的时间。

对发球力量有限的球员，这是最稳妥的一套。也可以：追身发球 + 下一拍打反方向。

发向弱侧套路 压制
旋转发球压一侧 → 第一拍仍然打这一侧 → 不急着立即变线 → 等短球出现再改变方向
发球球速的杠杆效应
足够高的球速可以把复杂战术压缩为简单两拍
大力一发 → 接发者只能挡回来 → 回球短或落点单一 → 发球者站在底线内打第一拍 → 整分由发球者控制

底线相持与得分
落点原则
  • 多打深区中央和对手脚下
  • 宁可用 70% 力量抢上升点，也不要退后用 100% 力量救球
节奏变化攻击 核心

挖掘对方正手或反手哪侧击球不稳定，不要每一拍都左右调动，可以连续攻击同一侧。

连续改变同侧击球高度，比单纯左右跑动更容易破坏击球节奏：

高弹球 → 低切削 → 再突然加速

完整序列：

高弧线上旋 → 低平切削 → 较快的平击球 → 再回到高球
不是用一记重拳打倒对手，而是让对手连续面对不同的问题
深球后上网 三拍套路
深球逼退 → 短球拉前 → 穿越或截击

不应把放短当作孤立的一拍。需要接受一定的上网失误，因为留在底线常规对抽，长期胜率更低。

高球压制接短球 压制
高而深的上旋打到对手正手 → 迫使她在肩部附近击球 → 回球变短时必须马上进入底线
防守反击模式 反击
对手先发力 → 用高球、深中路或切削防回 → 迫使对手重新组织 → 等对手站位偏向一侧 → 突然打直线、反方向或放短
进攻意识
不能只把对手打得不舒服，还必须趁对方不舒服时，主动把这一分拿下来
关键局策略 关键分

关键局不需要继续展示所有变化，重复当天成功率最高的模式，守住比分，让对手感受到压力。

被动防守与化解
核心原则

当来球又深、又快、又重时，不要强行抢直线、抡制胜分或者上网。

首先完成的是：把对手的进攻球降级成中性球（neutralize）
化解方式一：高而深的大斜线 最安全

斜线经过的场地更长，过网位置更低，借助上旋提高容错。目的不是反击，而是把对手推回底线，给自己更多回位时间。

化解方式二：深中路
  • 减少对手可利用的角度
  • 迫使对方从中心位置重新制造方向
  • 给自己更短的回位距离

被拉出边线时，打回深中路常常比赌博打反方向更合理

化解方式三：低切削或高吊球
  • 切削让球保持低，减少对方连续重击的舒适感
  • 高吊球增加飞行时间，让自己回位，并把对手推离底线
总结
面对重球：先让出空间，用紧凑动作打深中路或大斜线，化解对方主动；等短球出现，再收回站位
⚙
技术要点：缩短引拍
核心原则
来球越快，你的动作反而越要简单；来球越慢，你才有时间完整发力
好处与代价
✓ 好处
  • 更容易在身体前方击球
  • 更容易借力
  • 拍面更稳定
  • 恢复更快
✗ 代价
  • 降低绝对球速
  • 降低强烈旋转
  • 减少极端角度
  • 削弱一拍致胜

不是所有球都用，是在时间和空间受压缩时，用稳定换时间

借力的本质

对手提供速度，你提供拍面、方向和少量加速。类似接发球：面对 200km 的一发，接发者不会做完整大引拍，而是用紧凑动作借力回球。
