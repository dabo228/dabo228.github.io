圆明园
万园之园 · 无需预约 · 联票25元
推荐路线（3小时）
  • 南门入 → 绮春园（赏桃花，4月正盛）
  • → 福海东岸（皇家湖景，远眺蓬岛瑶台遗址）
  • → 西洋楼遗址区（大水法、海晏堂、黄花阵迷宫）
  • → 长春园北部（湖光山色）→ 南门出
不可错过
  • 大水法遗址：最具标志性的断壁残垣，历史课本上那张照片的实景。巴洛克式石柱在夕阳下特别出片
  • 桃花坞：4月初桃花盛花期，粉白花海配古建遗址的反差感很强
  • 黄花阵：欧式迷宫，全石砌筑，从高处可以看到全貌
  • 福海：曾经的皇家龙舟赛场，现在是北京最大的人工湖之一，湖边古柳成荫

国家自然博物馆
免费 · 需预约 · 清明假期最后一天不闭馆
重点展厅
  • 「鲸·奇」特展：鲸类生态展，4月6日最后一天，错过就撤了。从早期鲸到现代鲸的演化历程，真实骨架标本
  • 恐龙公园：国内最完整的恐龙化石集群之一，马门溪龙、井研龙骨架
  • 古哺乳动物厅：从始祖兽到猛犸象的演化链
  • 植物世界：从蕨类到被子植物的演化，化石标本+活体对照
  • 人体奥秘：时间够的话快速过一遍
建议路线（2.5小时）
  • 进馆直奔「鲸·奇」特展（展期最后一天，优先看）
  • → 恐龙公园（镇馆之宝）
  • → 古哺乳动物厅
  • → 植物世界（快速浏览）
从植物所到自然博物馆
西郊线植物园站 → 巴沟站
10号线巴沟 → 宋家庄方向
换乘到天桥站 B口出，步行5分钟
约 72分钟 · 费用约7元
天坛公园
联票34元 · 现场购买 · 世界文化遗产
不可错过
  • 祈年殿：三重檐圆形攒尖顶，纯木榫卯结构无一根钉子，中国古建筑最高成就之一
  • 回音壁：皇穹宇围墙，对着墙壁轻声说话对面能听到
  • 圜丘坛：古代皇帝祭天之所，站在天心石上说话有回声共鸣
  • 古柏林：600年古柏群，九龙柏是明代古树
  • 丹陛桥：连接圜丘和祈年殿的360米神道，中轴对称
建议路线（2小时）
  • 南门入 → 圜丘坛 → 回音壁
  • → 丹陛桥（感受中轴线）
  • → 祈年殿（拍照重点）
  • → 古柏林 → 东门出
中轴线巡礼
天安门 → 景山 → 前门 · 免费/2元
天安门广场 · 人民英雄纪念碑
  • 天坛东门出 → 地铁到前门站/天安门东站
  • 过安检进入广场，纪念碑近距离瞻仰
  • 傍晚时分光线很好，适合拍照
景山公园
  • 门票2元，从天安门步行穿过故宫东侧到景山北门
  • 登顶万春亭：北京中轴线最佳观景点，俯瞰故宫全景
  • 登顶约15分钟，日落前到山顶最佳
